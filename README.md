# نظام الأملاك والأوقاف — جمعية البر الخيرية بالقنفذة
**الإصدار 2.0** • Next.js 14 + PostgreSQL • سحابي ومحلي بنفس الكود

## التشغيل
| الطريقة | الخطوات |
|---|---|
| **سحابي** | ارفع المجلد إلى مستودع GitHub خاص ← Vercel: Import ← أضف `DATABASE_URL` (Supabase، Transaction pooler 6543) و`CRON_SECRET` ← Deploy |
| **محلي (شبكة الجمعية)** | ثبّت Node.js 20+ ← شغّل `start.bat` ← افتح `http://IP-الجهاز:3000` |
| **محلي بقاعدة PostgreSQL** | ضع `DATABASE_URL` في ملف `.env` ثم نفس الخطوة السابقة |

- أول دخول: `admin` / `admin123` ← يُطلب تغييرها.
- الجداول والبيانات الأولية تُنشأ تلقائياً عند أول تشغيل (بيانات التقرير التحليلي حتى 07/10/2026).
- التحديث المحلي: استبدل ملفات الكود (أبقِ `data` و`backups`) ← `update.bat`.

## النسخ الاحتياطي
| الطبقة | سحابي | محلي |
|---|---|---|
| مجدول يومي | Vercel Cron 02:00 الرياض (`vercel.json` + `CRON_SECRET`) ← Supabase Storage إن هُيّئ | تلقائي كل 24 ساعة أثناء التشغيل ← مجلد `backups` (أو `BACKUP_DIR`) |
| يدوي | شاشة «النسخ الاحتياطي» ← تنزيل ملف JSON كامل (بيانات + مرفقات) | نفسه |
| استعادة | رفع ملف النسخة + كتابة «استعادة» (تُؤخذ نسخة قبلها تلقائياً) | نفسه |
| مزود القاعدة | نسخ Supabase اليومية | — |

## الوحدات
- **مهامي اليوم**: مهام تتولد من البيانات؛ أعداد حسب النوع والعقار؛ أقساط كل مستأجر تحته بالمبلغ والأيام؛ إجمالي المتأخر مع التفقيط.
- **اللوحة التنفيذية**: الإيجار، المتأخرات، الإشغال، جودة البيانات، أعمار الديون، أكبر المتأخرين، أحداث 90 يوماً.
- **العقارات**: العقار مرسوماً كمبنى بحالة كل وحدة، العقود، الوحدات الفرعية، المستندات، الصيانة، المصروفات.
- **العقود / المستأجرون / الأقساط / المقبوضات**: سند قبض بالتفقيط وشعار الجمعية، إرفاق الإشعار عند التسجيل، حالة التوثيق (بلا مرفق ← موثق ← مطابق).
- **منصة إيجار**: استيراد ملف الأقساط (xlsx/csv)، ربط بعقد قائم أو إنشاء العقد منه، مقارنة حالة إيجار بالنظام.
- **كشف البنك**: حسابات بالآيبان، استيراد كشف بتعرّف تلقائي على الأعمدة وقالب محفوظ لكل حساب، منع التكرار.
- **المطابقة البصرية**: إيداع ← مقترحات (سند قائم أو قسط/أقساط بنفس المبلغ) مع درجة ترجيح وحالة إيجار ← إنشاء السند بضغطة.
- **الصيانة**: طلبات بصور وأولوية ومقاول، إغلاق بالتكلفة يسجل المصروف تلقائياً.
- **الاعتمادات**: الخصومات والاستثناءات لا تُطبَّق قبل الاعتماد؛ الطالب لا يعتمد طلبه.
- **تدقيق البيانات**: 17 قاعدة فحص، نسبة جودة، استثناء على مستوى سجل أو تاريخ أو عقار بمبرر ومعتمد وتاريخ انتهاء، وملاحظات المراجعة المستوردة.
- **التقارير**: المتأخرات، أعمار الديون، المطابقة الثلاثية، التجديدات، الأقساط التي تحتاج تأكيداً، التحصيل، أداء العقارات + تصدير إكسل (بلا دمج خلايا، بصيغة التاريخ المختارة).
- **الإدارة**: الهوية (شعار، 4 ألوان، مجموعات جاهزة، خط افتراضي)، صيغة التاريخ، إقفال الفترة، المستخدمون، سجل العمليات.
- **لكل مستخدم**: صيغة التاريخ، نوع الخط، حجمه (أ− / أ+ في أعلى كل شاشة).

## الصلاحيات
مدير النظام: كل شيء + الاعتماد • محاسب: الإدخال والمطابقة وطلب الخصم والاستثناء • اطلاع: عرض وطباعة وتصدير.
